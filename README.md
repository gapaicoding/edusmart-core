# EduSmart Core

Create a minimal project shell for "EduSmart SchoolOS".

Important:

- Use the already connected existing Supabase project only.

- Do NOT create, alter, rename, or delete any database tables.

- Do NOT modify RLS policies, database functions, triggers, roles, or permissions.

- Do NOT create authentication flows yet.

- Do NOT implement product features yet.

- Do NOT create Finance, PPDB, LMS, AI, CRM, HR, Library, or other modules.

For now, only create a clean minimal application shell so the project exists and can be configured further.

Use React + TypeScript + Tailwind + shadcn/ui.

Keep the UI minimal.

This project was built with [Lovable](https://lovable.dev).
